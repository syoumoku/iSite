# iSite2 Output Rules

Default outputs:
- Main.
- Evidence.
- Model Detail.
- Parameters.
- Review Queue.
- Method.
- Legend.
- Country Summary for batch scans.

Main table stays short and hard:
- Keep property-specific facts, result classes, recommended solution, reason, and next action.
- Do not repeat source-tier definitions, formula explanations, proxy definitions, or scenario parameters row by row.

Evidence table must preserve field-level source chain. Inference table must preserve inferred field, value, basis, chain, and confidence.

Map outputs must include only map-ready coordinates. Top N filters are presentation-only and must not change the underlying candidate pool.
