# iSite2 Evidence Rules

Evidence precedes judgment. Strong value, action, solution, or build-status statements require traceable source URL, source name, source tier, source date, fetched date, field group, field value, evidence type, and cross-check status.

Source tiers:
- Tier 1: official venue/operator/government/regulator/airport/transit/hospital/university/developer materials, annual reports, ESG/investor filings.
- Tier 2: industry associations, authoritative consultants, exchange/regulatory notices, reliable restatements of official numbers.
- Tier 3: OTA, maps, event platforms, real-estate platforms, aggregators, secondary references, news summaries.

Cross-check rules:
- Prefer 1 Tier 1 source plus 1 independent Tier 2/3 corroboration.
- Accept 2 independent Tier 2 sources for supported status.
- A single directly relevant Tier 1 field may be verified for that field, but still flag missing cross-check where business-critical.

Conflict rules:
- Preserve conflicting values with dates and sources.
- Use conservative values only with an assumption note.
- Never overwrite direct evidence with inference.
- Unresolved conflicts create concrete Review Queue actions.

Freshness:
- Tier 1 critical sources refresh every 30-90 days.
- Planned/build projects refresh every 14-30 days.
- Open Review Queue items refresh every 7-14 days.
