# Codex Task 05 — World Map UI

## Goal

Create the first UI shell for the world map product.

## Suggested stack

Next.js + TypeScript + Mapbox GL or Leaflet.

## Implement

- Map page with filters.
- KPI bar.
- Marker clustering.
- Property drawer.
- Evidence tab.
- Inference tab.
- Review tab.
- Export buttons as disabled or stubbed actions until output service is connected.

## Acceptance

- UI can consume `/map/properties`.
- Filtering updates markers and KPI.
- Clicking marker opens property drawer.
