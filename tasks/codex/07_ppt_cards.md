# Codex Task 07 — PPT Insight Cards

## Goal

Generate single-site insight-card PPT deck.

## Implement

- PPT deck service using python-pptx.
- Cover page.
- Rule/advancement logic page.
- Optional portfolio snapshot.
- Single-site cards.
- Observation list cards.

## Card fields

- Site name / country / city
- Scene type
- Recommended solution
- Evidence Status / Value Class / Action Class
- Core objective metric
- Busy-hour users / traffic / bandwidth
- Area / scale field
- Coordinates and geocode precision
- Build status
- Value judgment short sentence
- Risk and next action
- Evidence entries
