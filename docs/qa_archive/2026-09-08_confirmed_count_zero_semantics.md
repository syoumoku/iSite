# 2026-09-08 Confirmed-count zero semantics

## Incident

六国五场景互联网统计初版把“没有取得可批量联结的全国物业表”错误地表现为部分国家五星级酒店或医院确认数为 0。该数字只能说明批量数据源缺口，不能说明逐物业互联网补查后没有可确认达标物业。

## Root cause

- 统计管线优先使用全国目录或结构化表，并把未能完成批量 join 的组合直接留为 0。
- 零项没有触发逐物业补查，非零项与零项没有在最终输出前执行同一证据门槛审计。
- 输出说明虽然提示“0 不等于不存在”，但仍把采集覆盖缺口写入了统计数字。

## Correction

- 对零项执行逐物业补查，只纳入同时具备明确物业身份、场景资格、物业级主指标且严格超过门槛的记录。
- 对所有已有非零记录重新执行相同的门槛、单位、实体、去重和来源检查。
- 跨页面联结时同时保留主来源和补充来源链接。
- 修订版由 873 条增加至 923 条；五星级酒店从 283 增至 323，医院从 377 增至 387。
